# Tài liệu chung của nhóm

Thư mục này chứa thứ vượt ra khỏi một slice: kiến trúc tổng thể, tài liệu báo cáo cuối kỳ, quy ước đặt tên, biên bản phân công.

Tài liệu **của riêng một slice** thì nằm trong chính slice đó, ví dụ schema và bàn giao dữ liệu ở [`../2-processing/docs/`](../2-processing/docs/).

Sửa file trong thư mục này phải mở Issue trước (xem [`../CONTRIBUTING.md`](../CONTRIBUTING.md) mục 1).
